Capítulo 01

Conceptos Clave

Contexto, relevancia, y métricas de evaluación.

1. ¿Qué es Ingeniería de Contexto?

La ingeniería de contexto es el proceso de optimizar el contexto proporcionado a los modelos de lenguaje para mejorar la precisión y relevancia de las respuestas. Se realiza mediante la selección y organización de información relevante.

Capítulo 04

Pipeline de Contexto

Implementación del pipeline de contexto.

1. Pasos del Pipeline

  1. Selección de Contexto: recolección y limpieza de contexto.
  2. Organización del Contexto: estructura del contexto.
  3. Optimización del Contexto: ajuste del contexto con datos específicos.
  4. Evaluación: medición de métricas de rendimiento.

2. Ejemplo de Código

Python 
from langchain import PromptTemplate, LLMChain
from langchain.llms import OpenAI

# Configuración del modelo
llm = OpenAI(temperature=0.7)

# Plantilla de contexto
prompt_template = PromptTemplate(
    input_variables=["context", "question"],
    template="Contexto: {context}\n\nPregunta: {question}\n\nRespuesta:"
)

# Creación de la cadena
chain = LLMChain(llm=llm, prompt=prompt_template)

# Ejecución con contexto
context = "La ingeniería de contexto es crucial para mejorar la precisión de los modelos de lenguaje."
question = "¿Por qué es importante la ingeniería de contexto?"

response = chain.run({"context": context, "question": question})
print(response)

Capítulo 05

Evaluación

Métricas de evaluación y validación del modelo.

1. Métricas Clave

  • Precisión: porcentaje de respuestas correctas.
  • Recall: capacidad de identificar todos los casos positivos.
  • F1-Score: media armónica de precisión y recall.

2. Validación del Modelo

La validación del modelo se realiza mediante la evaluación de métricas en un conjunto de datos de prueba. Esto permite medir la precisión y relevancia del modelo en casos de uso reales.
